# Free Game Explorer App

Aplikasi mobile berbasis Flutter yang menyajikan katalog game gratis secara real-time menggunakan REST API dari FreeToGame.

## Fitur Utama
- **Katalog Game Gratis:** Menampilkan daftar game lengkap dengan gambar thumbnail, genre, dan platform.
- **Halaman Detail Game:** Menyajikan informasi detail seperti deskripsi singkat, developer, publisher, dan tanggal rilis.
- **Asynchronous Data Handling:** Penanganan kondisi Loading, Success, dan Error secara dinamis beserta tombol retry.

## Teknologi & Package
- **Framework:** Flutter
- **Bahasa:** Dart
- **Package:** `http: ^1.2.0`
